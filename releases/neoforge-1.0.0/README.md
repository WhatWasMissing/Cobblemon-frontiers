# Cobblemon Frontiers & Gacha — NeoForge 1.0.0

Built for Minecraft 1.21.1 with Java 21 and Gradle 8.11. This release folder contains the current NeoForge jars and source snapshots for both mods. The source archives omit generated build outputs and Gradle caches.

## Files

- `cobblemon_gacha-neoforge-1.0.0.jar` — Cobblemon Gacha
- `cobblemon_spawn_announcements-neoforge-1.0.0.jar` — Cobblemon Frontiers
- `cobblemon-gacha-1.0.0-source.zip` — Gacha source
- `cobblemon-frontiers-1.0.0-source.zip` — Frontiers source

Only NeoForge jars are included in this release bundle.
