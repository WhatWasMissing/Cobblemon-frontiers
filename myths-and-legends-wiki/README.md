# Myths and Legends: a player’s field guide

Trying to work out where a Legendary went, what that strange key item does, or why nothing is spawning? You’re in the right place. This is a practical community guide to **Myths and Legends**, the Cobblemon sidemod by D0ctorLeon. It brings together the encounter routes, item reference, server setup notes, and answers to the problems players most often run into.

> **Version scope:** The encounter catalogue in this wiki is generated from official datapack commit `cbeea17321cca730b0ff896be1f229c14ef06396`, inspected on 25 September 2026. It describes the official datapack definitions at that commit; a server may use a different datapack version or custom overrides. Item names/descriptions and configuration notes are based on the local Myths and Legends NeoForge 1.9.0 installation. The compatibility notes for **Myths and Legends Direct Spawn Fix** describe the separate server-side patch present in this workspace and do not describe official mod behavior.

## What this wiki covers

Here’s the detail that causes the most confusion: in the usual setup, carrying a key item does not summon a Pokémon on demand. It helps make an encounter eligible; the biome and any other conditions still need to line up, and Cobblemon still has to roll that spawn. Version 1.4 and later also use a separate companion datapack for the ready-made encounters, so the mod and datapack both need to be installed.

This is an independent community guide, not the official project wiki. Versions and custom datapacks can change the details, so compare these notes with the files your server actually uses when something doesn’t match.
